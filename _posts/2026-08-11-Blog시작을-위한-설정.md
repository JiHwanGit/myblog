# Blog시작을-위한-설정 
 
## 문제 : 블로그 경로가 복잡하여 작성시 찾는 불편함

### 간단한 해결 방법
1. 바탕화면에 경로의 바로가기를 만든다.

### 자동으로 블로그 셋팅해주기
- window명령어 프롬프트를 이용한 배치스크립트 활용(.bat)
1. 텍스트 파일(.txt)로 명령어 프롬프트를 작성한다.
2. 확장자 명을 .bat로 바꿔준다.

bat?
윈도우 배치 스크립트
셀 스크립트 언어

```bat
@echo off
chcp 65001 > nul

:: 1. 오늘 날짜를 YYYY-MM-DD 형식으로 추출
set YYYY=%date:~0,4%
set MM=%date:~5,2%
set DD=%date:~8,2%
set TODAY=%YYYY%-%MM%-%DD%

:: 2. 카테고리 선택 (Security, WebDev, AI, GameDev)
echo.
echo =========================================
echo  📁 카테고리를 선택하세요
echo =========================================
echo  1. 직접 입력
echo  2. Security (보안)
echo  3. Blog (블로그)
echo =========================================
set /p CAT_CHOICE="번호를 입력하세요 (기본값 1): "

if "%CAT_CHOICE%"=="1" set /p CATEGORY="카테고리명을 직접 입력하세요: "
if "%CAT_CHOICE%"=="2" set CATEGORY=Security
if "%CAT_CHOICE%"=="3" set CATEGORY=Blog
if "%CAT_CHOICE%"=="" set /p CATEGORY="카테고리명을 직접 입력하세요: "

if "%CATEGORY%"=="" set CATEGORY=Security

:: 3. 태그 입력 (여러 개 지원)
echo.
echo =========================================
echo  🏷️ 태그를 입력하세요 (쉼표로 구분하여 여러 개 가능)
echo  예: TIL, Troubleshooting, Blog
echo =========================================
set /p TAG_NAME="태그 입력 (엔터만 누르면 'TIL'): "
if "%TAG_NAME%"=="" set TAG_NAME=TIL

:: 4. 포스팅 파일명 및 주제 입력
echo.
set /p POST_NAME="포스팅 주제/제목을 입력하세요 (엔터만 누르면 'note'): "
if "%POST_NAME%"=="" set POST_NAME=note

:: 5. 블로그 포스팅 폴더 경로 및 파일 경로 설정
set BLOG_DIR=(**블로그 경로**)\_posts

:: 공백(띄어쓰기)을 하이픈(-)으로 치환하는 핵심 구문
set BLOG_DIR=%BLOG_DIR: =-%
set TODAY=%TODAY: =-%
set POST_NAME=%POST_NAME: =-%

set FILE_PATH=%BLOG_DIR%\%TODAY%-%POST_NAME%.md

:: 6. 파일이 없다면 최솟값 템플릿 작성 후 생성
if not exist "%FILE_PATH%" (
    echo --- > "%FILE_PATH%"
    echo layout: post >> "%FILE_PATH%"
    echo title: "%TODAY% %POST_NAME%" >> "%FILE_PATH%"
    echo categories: [%CATEGORY%] >> "%FILE_PATH%"
    echo tags: [%TAG_NAME%] >> "%FILE_PATH%"
    echo --- >> "%FILE_PATH%"
    echo. >> "%FILE_PATH%"
    echo # %POST_NAME% >> "%FILE_PATH%"
    echo. >> "%FILE_PATH%"
)

:: 7. VS Code로 해당 파일 열기 및 터미널 종료
code "%FILE_PATH%"
exit
```
*AI 이용한 명령 프롬프트이다.
수정할 일이 있다면 직접 수정할 수 있다.

결과
```text
파일은 xxxx-xx-xx-(포스팅 주제/ 제목).md으로 열어준다.
만일, 동일 파일이 있을 경우 그 파일을 열어준다.
```

## 문제 : 윈도우 시작 시 바로 열고 싶다.

### shell:startup

1. <kbd>Ctrl</kbd> + <kbd>R</kbd> 실행창 을 열고
2. shell:startup 입력 후 해당 파일(.bat)을 넣어준다.

## 마무리
블로그 경로 진입의 단순화를 통해 파일 열기가 쉬워졌다.
윈도우 시작시에 다른 곳에 한눈 팔지 않고 하루에 한번씩 작성하도록 유도 할 수 있다.
