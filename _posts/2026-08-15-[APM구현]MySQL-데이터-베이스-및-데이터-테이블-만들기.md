# [APM구현]MySQL-데이터-베이스-및-데이터-테이블-만들기 

관련 [공식홈페이지](https://dev.mysql.com/doc/refman/9.7/en/database-use.html])를 참조하여 작성

해당 정리는 캡처 이미지 위주의 workbench 보다 코드블록 위주의 command line로 기록하는게 보기 좋다 생각하여 command line으로 정리하였다.
단, 추후 복잡한 데이터 관계도의 경우 workbench로 정리하고자 한다.

## 순서 
1. command line 진입
2. 데이터 베이스 생성
( + 터미널에서 mysql 데이터베이스 까지 접속하기)
2. 데이터 테이블 생성
3. 기본으로 사용 할 데이터 생성

### 2. 데이터 베이스 생성

user 데이터 베이스 생성 쿼리
```sql
CREATE DATABASE sql_1;
```
확인하기
```sql
SHOW DATABASES;
```
```text
+--------------------+
| Database           |
+--------------------+
| information_schema |
| mysql              |
| performance_schema |
| sql_1              |
| sys                |
+--------------------+
5 rows in set (0.00 sec)
```

그 외 추가 명령어
데이터베이스 삭제
```sql
drop sql_1;
```
데이터베이스 선택()
```sql
use sql_1;
```
### + 터미널에서 mysql 데이터베이스 까지 접속하기
전역변수 (MySQL\MySQL Server 8.0\bin) 추가했다면
```sql
mysql -h [호스트] -u [유저이름] -p[데이터베이스];
```

터미널에서도 접속이 가능하다.
```cmd
mysql -u root -p
```


### 3. 데이터 테이블 생성

테이블 만들기
```sql
create table user (
    id VARCHAR(20), 
    pw VARCHAR(20), 
    info VARCHAR(20)
);
```
테이블 확인
```sql
show tables;
```
```text
+-----------------+
| Tables_in_sql_1 |
+-----------------+
| user            |
+-----------------+
1 row in set (0.00 sec)
```
테이블 구조 확인
```sql
DESCRIBE user;
```
```text
+-------+-------------+------+-----+---------+-------+
| Field | Type        | Null | Key | Default | Extra |
+-------+-------------+------+-----+---------+-------+
| id    | varchar(20) | YES  |     | NULL    |       |
| pw    | varchar(20) | YES  |     | NULL    |       |
| info  | varchar(20) | YES  |     | NULL    |       |
+-------+-------------+------+-----+---------+-------+
3 rows in set (0.00 sec)
```
field type null key Default Extra 나중에 정리하기

### 기본으로 사용 할 데이터 생성

데이터 추가하기
```sql
INSERT INTO user VALUES ('admin', 'admin1234', 'imadmin');
```

데이터 확인하기
```sql
SELECT * FROM user;
```
```text
+-------+-----------+---------+
| id    | pw        | info    |
+-------+-----------+---------+
| admin | admin1234 | imadmin |
+-------+-----------+---------+
1 row in set (0.00 sec)
```
