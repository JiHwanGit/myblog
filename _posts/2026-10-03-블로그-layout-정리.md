# 블로그-layout-정리 
 
다양한 방법으로 수정할 수 있는 gitpage의 jekyll의 수정 방법 및 구조를 정리하였다.

# 추가된 파일
메인 블로그에 추가된 폴더와 파일이다
```
┬includes ┬ header.html
│         ├ sidebar.html
│         └ footer.html
├layouts  ┬ default.html
│         ├ home.html
│         └ post.html
│ 
└ assets  ─ css ─ style.scss
```
include<span style='color: red'>s</span> 폴더명에 s를 넣어야한다.

includes는 각각 기본적으로 불러올 파일
layouts 페이지 마다 레이아웃
기본적으로 수정할 경우 default로 수정하고 안정될 경우 home으로 밀어 넣는다.
html을 불러올 경우 코드

```html
{% raw %}
<header>
  {% include header.html %}
</header>
{% endraw %}
```
