# git_병합하기 
 
## 직접 사이트로 올리는 main과 작업하는 공간 분리
- main을 블로그 올리는 공간 ji를 작업하는 공간으로 분리
- 작업이 끝나고 main에 ji을 병합하여 올리기

### 작업이 끝나고 커밋과 푸시
```cmd
git add .
git commit -m "오늘은 뭐했을까?"
git push
```

### 브런지 이동
```cmd
git checkout main
```

### 병합하기
```cmd
git merge ji
```


### 마무리 
- 추후 병합 작업을 하면서 생기는 문제들을 여기에 기록할 계획이다.
